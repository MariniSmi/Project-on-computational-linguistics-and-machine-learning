Классификация текстов английского языка по уровням CEFR(A1-C1)

Проект по компьютерной лингвистике и машинному обучению, посвящённый анализу и многоклассовой классификации текстов английского языка по уровням сложности CEFR(A1-C1).

В рамках проекта я исследовала корпус текстов разных уровней CEFR: проводила лингвистический анализ, предобработку и аугментацию данных, после чего использовала модель машинного обучения для определения уровня текста.

На этапе машинного обучения был акцент на сравнении двух подходов к представлению текстов в числовом виде: TF-IDF и эмбеддингов предобученной модели BERT.

Данные:

Исходный корпус содержал 200 текстов пяти уровней английского языка (A1, A2, B1, B2, C1) с различной тематикой, стилем и уровнем сложности. В результате аугментации удалось расширить корпус до 1400 текстов.

Основные этапы
1. Предобработка текстов
   
Для предобработки корпуса использовались инструменты Python и NLP-библиотеки spaCy, NLTK и Stanza и были проведены следующие действия:
1) удаление именованных сущностей (NER);
2) токенизация;
3) приведение текста к нижнему регистру;
4) удаление стоп-слов;
5) лемматизация;
6) POS-tagging;
7) синтаксический анализ на основе Universal Dependencies.
   
2. Лингвистический анализ корпуса

Для исследования различий между текстами разных уровней рассчитывались лингвистические характеристики:

1) TTR (Type-Token Ratio), показатель лексического разнообразия;
2) частотность частей речи;
3) синтаксические зависимости (например: conj, advcl, ccomp, xcomp);
4) косинусное сходство текстов;
5) TF-IDF.

Для визуализации результатов анализа я использовала matplotlib.

3. Аугментация данных

Для увеличения объёма корпуса применялась аугментация текстов методом back translation.

Работа была построена таким образом: с помощью предобученных моделей с Hugging Face я переводила тексты из своего корпуса на немецкий и затем обратно на английский.

Для тех же целей я прибегала к генерации текстов через подключение к API GigaChat.

4. Представление текстов в числовом виде

Для решения задачи классификации сравнивались два подхода к представлению текстов: TF-IDF и BERT embeddings.

1) TF-IDF

Тексты преобразовывались в разреженные числовые векторы с использованием TfidfVectorizer.

Использовались:

- униграммы, биграммы и триграммы;
- ограничение словаря по количеству признаков;
- фильтрация редких слов.

2) BERT embeddings

Для получения контекстных представлений текста использовалась предобученная модель BERT (bert-base-uncased).

Полученные эмбеддинги использовались как числовые признаки для последующего обучения классификатора.

5. Классификация

Задача формулировалась как многоклассовая классификация: по тексту необходимо определить один из пяти уровней CEFR: A1, A2, B1, B2 или C1.

Для классификации использовалась модель CatBoostClassifier.

Обучение и тестирование проводились на разделенных выборках с сохранением распределения классов.

Были рассмотрены два варианта:

1) TF-IDF → CatBoost

2) BERT embeddings → CatBoost

6. Оценка качества

Качество классификации оценивалось на тестовой выборке с помощью стандартных метрик:

- Accuracy;
- Precision;
- Recall;
- F1-score;
- Confusion Matrix.

Для варианта с BERT embeddings и CatBoost accuracy на тестовой выборке составила 86,4%.
